# 风之翼：晴空滑翔竞速 (Wind Glider: Sky-Sea Race)

> 一款基于 Three.js + TypeScript 的吉卜力水彩手绘风水上与空中滑翔竞速游戏。

---

## 🌟 游戏概览与美术愿景

本项目由《Board Race》核心竞速引擎重构复刻而来。游戏告别了冷硬的赛博工业感，转向**温暖、治愈、充满自然与机械浪漫的吉卜力 / Solarpunk 水彩画风**（致敬《风之谷》《红猪》《塞尔达传说：风之杖 / 王国之泪》）。

玩家驾驶一艘**复古木质水翼滑翔艇（Wind Glider Skiff）**，在水下流动着金色焦散光斑的碧蓝海面上疾驰。通过切水漂移积蓄风之能量，展开帆布滑翔翼借助热气流腾空而起，在花瓣与蒲公英飞舞的晴空云海中穿梭古代白石拱门。

### 核心玩法循环
- **自动巡航**：快艇自动全速前进，双侧木质水翼劈开浪花，玩家掌控航向、高度俯仰与路线选择。
- **水面切水漂移蓄力（Shift）**：木质水刀大角度侧倾切水，激起双弧白色水幕与彩虹水雾，蓄积风能与风之能量石。
- **释放风能冲刺（Boost）**：过弯后松开漂移，帆面张满产生强烈推背感，尾部激荡环形白色气流冲击波。
- **展开滑翔翼起飞与续航（Space）**：消耗风力能量石腾空起飞，在半透明水彩风道中穿过发光的古代藤蔓石拱门，飞行中再次点击 Space 消耗备用能量石进行空中续航。
- **真实空气动力学（AoA 升力与俯冲俯仰 W / S）**：通过俯冲下压机头将重力势能转化为极速动能（最高达 56 m/s），拉起机头将动能转换为爬升高度，平飞自然后沉。
- **翼地效应 (Ground Effect) 掠海共鸣**：离海面或崖壁 0.9~2.2 米贴地飞行时触发空气垫浮力与速度增益，生成贴水白色风纹与掠海共鸣充能。
- **上升暖气流柱 (Thermal Updrafts) 与高空风道 (Wind Tunnels)**：穿越旋转上升的暖气流柱获得强力垂直抬升，进入高空风环导流管获得极速弹射推进。
- **空中气动制动（Air-Brake - Shift）**：飞行中按住 Shift 调节滑翔翼仰角，实现精准空中减速与急速变向。
- **终点与庆典**：完成 7 次航道飞越后，进入黄金风向标终点站，迎来漫天花瓣、彩纸与群鸟伴飞的探索家授勋盛典。

## 🎮 操作指南

| 键位 (PC) | 触控 (移动端) | 游戏动作 | 视觉与物理反馈 |
| :--- | :--- | :--- | :--- |
| `A` / `D` 或 `←` / `→` | 左侧虚拟摇杆/左右轻触 | 艇体航向转向与机翼侧倾 | 木质方向舵偏转，机翼侧倾入弯，水翼拉出流线 |
| `W` / `S` 或 `↑` / `↓` | 上下虚拟推杆/倾斜控制 | 空中气动俯仰 (俯冲/仰冲) | 俯冲换速（视角拉远/广角张开），仰冲爬升（视角拉近） |
| `Shift` (按住) | 右下角 `漂 / 刹` | 水面切水漂移 / 空中阻尼 | 水刀深切入水蓄能 / 帆翼扬起空气刹车扰流 |
| `Space` | 右侧 `飞` | 展开滑翔翼起飞 / 空中续航 | 帆布翼展开，气流托举升空，飞舞花瓣与白色风流线 |
| `Enter` / `Space` | 屏幕点击 `GO` | 从 READY 界面开始 / 重新挑战 | 阳光洒满海面，3·2·1 倒计时起航 |
| `Esc` | 顶部 `跳过` | 关闭新手提示 | 沉浸式全屏竞速 |

## 🏗️ 架构与技术栈

- **渲染引擎**：Three.js (r185) + 原生 WebGL GLSL Shaders。
- **物理与循环**：60Hz 固定步长（Fixed-step）模拟，确定性水面浮力（5阶 Gerstner 波算法）。
- **着色器体系**：
  - `toonMaterial.ts`：4阶手绘水彩渐变着色器（双半球天光漫射、无塑料感高光与微抖墨线）。
  - `ocean.ts`：带双层水下焦散（Caustics）、次表面阳光透光与动态蕾丝浪沫（Foam Lace）的无缝海面。
  - `sky.ts`：4层立体手绘蓬松积雨云群（Cumulonimbus）、晴空穹顶与体积阳光。
  - `postPipeline.ts`：水墨手绘边缘风流速度线（Ink Streamlines）与柔和辉光泛光通道。
  - `spray.ts` & `jetTrail.ts`：飞舞花瓣、蒲公英种子、翼尖涡流与白色风流线粒子系统。
- **3D 奇观航道**：
  - 5 大主题地貌（Zone 1 起飞悬崖、Zone 2 珊瑚环礁、Zone 3 峡谷天梯、Zone 4 浮岛空中悬廊、Zone 5 海蚀天生巨拱）。
  - 7 道贯通云海的天光光柱（God Rays）与 Solarpunk 天体罗盘地标。
- **零外部重型依赖**：所有船体、风帆、浮标、石门与景物均为纯代码参数化数学建模生成，秒级极速加载。

## 🛠️ 本地运行与构建

```bash
# 进入项目目录
cd /var/www/wind-glider

# 启动本地开发服务 (默认端口 5173)
npm run dev

# 生产环境构建与类型检查
npm run build

# 运行自动化测试与物理契约验证
npm run verify:release

# 运行安全受控发布与 GitHub 仓库就绪
npm run release:checked
```
