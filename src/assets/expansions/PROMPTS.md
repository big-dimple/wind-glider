# Expansion Gallery Image Prompts

These seven images preview seven planned games in one connected project, not seven
skins for one vehicle. Every game changes the playable body, locomotion, scale,
materials, and environment. The shared identity comes only from the cel-shaded art
direction, camera energy, cyan route accents, golden checkpoints, and gallery
composition.

Generate each image at `2048x1152` (16:9). Export the selected result as WebP under
350 KB when practical, using the filename shown below. Each block is self-contained
and can be copied into an image generator without any shared prefix.
