## 🚀 快速验证指令 (Quick Verification)

直接在终端执行全量发布契约测试：

```bash
# 1. 编译校验
npm run build

# 2. 全量契约与端到端自动化测试
npm run verify:release
```

若某项失败，可单独运行对应专项排查：
- `npm run verify:flight` （飞行气动与手柄）
- `npm run verify:collision` （3D 航道与碰撞判定）
- `npm run verify:audio` （Web Audio 混音与事件）
- `npm run verify:systems` （AI 与比赛记录）
- `npm run verify:mobile` （移动端虚拟摇杆与布局）
