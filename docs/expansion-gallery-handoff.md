# 资料片画廊开发交接

状态：`gallery-shell-integrated / expansion-gameplay-pending`

## 当前用户体验

资料片画廊从 Final 结算页进入，进入时游戏保持冻结，不重置本局。
它是全屏单页浏览器：一页一个待开发游戏，一张全幅概念图，左下叠加
中文游戏名、移动方式和一句玩法预告。

- 七个底部中文页签可直接跳页，当前页使用金色顶线和高亮文字。
- 左右箭头翻页；第一页和最后一页不会循环，避免误跳到另一端。
- PC 支持 `←` / `→` 和 `A` / `D`；手机支持 34px 以上的左右滑动。
- `Esc`、右上角 `返回结算` 都回到冻结的 Final 结算页。
- 只有 Final 页的 `继续游戏` 会进入同一局的恢复倒计时；浏览画廊不会继续消耗比赛时间。
- 每次只请求当前页图片，不预取邻页；加载期间锁住翻页并显示明确进度，失败时可重试或返回结算。
- 手机打开画廊后隐藏转向、漂移和飞行控件，退出后恢复；页面浏览写入本地
  `expansionSeenMask`，不发送网络埋点。

运行时入口：`src/hud/expansionGallery.ts`；布局：
`src/hud/expansionGallery.css`；图片和中文名映射：
`src/assets/expansions/`。当前七张 WebP 是可随时替换的一次性概念图，
不是需要追溯或长期保存的母版；长期合同只有中文游戏定义、语义文件名和
`src/assets/expansions/PROMPTS.md` 的重绘规格。

## 待开发顺序

1. **资料片各自的可玩化身**：画廊图已经不再是赛艇换背景，但运行时仍只有
   海上赛艇。未来应为每个世界定义独立 avatar、移动规则、碰撞体、镜头和
   能力反馈；不能只替换纹理。
2. **统一动作语法的主题翻译**：保留“蓄力过弯 -> 获得跃迁资源 -> 主动穿越
   关键门”的街机节奏，但分别映射为切沙/滑翔、磨轨/换线、甩尾/跳跃、
   弹跳/摆荡、换手/飞越、折翼/爬升、鞭毛/流体加速。
3. **资料片独立规则与教学**：每个游戏需要自己的失败原因、首次教学、音效
   词汇、HUD 近体反馈和可访问性说明，不能复用船的 `flightRemaining` 文案。
4. **画廊最终美术验收**：正式图需在 16:9 和 844x390 横屏裁切下保持主体、
   移动动作和下一道金色检查点可见；标题继续由 HTML 叠加，不烘焙进图片。

Final 结算视觉已完成：冲线后的世界舞台、金柱爆闪、粒子冠、镜头冲击和延迟
出现的结算操作已集成；`shots/final-station-hero.png` 与
`shots/final-station-settled.png` 是对应的确定性验收帧。后续只需在资料片
独立立项时推进上面的玩法与美术工作。
